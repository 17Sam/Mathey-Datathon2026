# Mathey
Mathey is an AI assistant which helps you practice Cangur-style math problems effectively. It was developed for the 2026 Datathon.

The repository includes code designed to run on an Arduino Q.

### Features
**Locally hosted AI Model**: No connection required, just connect to the web and be ready to learn.

**Hint-induced learning**: Mathey can guide you toward the answer, not necessarily revealing the answer so that you truly understand the math problem.

**Local host web service**: Host a web with a neat graphical interface to interact with Mathey.

**LED Matrix feedback**: Uses the built-in LED Matrix to display the state of Mathey, such as readiness, thinking or loading.

### AI Models
The model runs with two AI models: `Qwen3.5-0.8B` and `bge-small-en-v1.5-q8_0`.
